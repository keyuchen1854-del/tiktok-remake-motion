# 反推＋短动效工作流

1. **开工。** 读取项目 [AGENTS.md](../../../AGENTS.md) 和 [首次配置说明](../../../README.md#首次配置)。只发参考视频且改动未说明时，按原问句补问，收到答复后再打开素材。明确改动或「按原片复刻」按原项目条件执行。用户已授权从验收底片接续时，运行 `check` 取得工具路径，记录接续依据并从第 3 步执行。
2. **执行原带货出单复刻。** 在新项目根目录运行 `python tools/workflow.py check`。读取结果中的 `remake_rules` 和 `remake_skill` 并完整执行。完成底片技术检查和审看后继续第 3 步，原技能的最终交付检查用在加完动效的全片及需审看的代表段。原项目的相对路径以 `remake_rules` 所在目录为准，需要在原目录执行的命令使用该工作目录。原技能内部调用 `video-reverse`，依次做商品取证、真实切点、逐镜改写、单图和宫格、宫格确认、Capsule 校验、H3 代表段、代表段验收、逐段生成与回拼验收。保持原项目的模型、素材、费用权限及重试条件。将本单素材和回拼验收记录存入本项目的 `runs/<本单目录>/`，调用原工具时传入该产物的实际路径。
3. **底片通过即接力。** 把实际通过的 MP4 作为底片。用第 2 步找到的 `reverse_collector` 重取该版底片的帧时钟和候选切点，目视确认真实镜头边界。按[交接格式](references/handoff.md)整理实际底片、通过依据、镜头、目标语口播或字幕、核实的商品卖点和本次要求，运行 `prepare`。成功后继续 Lemo。底片指纹、时码或验收依据有缺项时回到对应步骤补齐。
4. **Lemo 动效。** 读取 `lemo_skill` 和 `lemo_rules`，使用本机已有 Lemo。把 `handoff.json` 中的镜头、口播、卖点证据和本次要求作为简报，在该单的 `film/` 写制作方案和动效工程。逐镜抽帧定位商品与动作，设置标注的起止、坐标和切点变化，给字卡留阅读时间。保留已验收底片的节奏、可见商品结构和原口播音轨。只有底片指纹和时间线相同，才复用既有逐帧坐标。下载、安装按用户授权执行。
5. **渲染和交付。** 按[交接格式](references/handoff.md)运行 `render`。审看原有字幕、重点动作、描线与商品结构、字幕阅读和口播同步，做有声检查并记录实际范围。修正动效时复用同一底片和时码。通过后对该版 MP4 调用原项目 `preview_tool`，以默认暂停的对话内预览加文件链接交付一条完整成片。底片、交接单与动效工程留在本单目录，代表段交付仍按原项目规则。
