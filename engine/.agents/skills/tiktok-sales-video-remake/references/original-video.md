# 原创带货与制作交接

## 从商品到对标

1. 用同站同款同变体的商品页、用户实拍、说明书或实际演示建商品证据表。每项写证据编号、来源及图位或时码、可用表达和待核实项。颜色、形状、件数、开合/穿用方向及动作限制以对应实物为准。卖家表述和实拍证明各自登记。效果、材质、价格、规格或附赠配件要有对应证据，生成画面只能作为演绎。
2. 从已核实的站点和同类用途定可比范围，按目标变体的当地可比到手价格定价格带，写币种、时间、优惠与运费口径。优先同站点、同类需求、同价格带的近期带货作品，同时找可比普通样本。记录广告和自然流情况，未知就标出。用 已安装的 $tiktok-shop-analytics 核对现有导出或查询结果的 ID、来源、重复、币种、时间窗和字段含义。订单、销量或 GMV 有可比证据时用于判断成交信号。播放和互动只支持内容观察。
3. 先复用已有且时效合用的记录。需要补数且在已授权额度内时载入 已安装的 $fastmoss，按现有 MCP 或 CLI 的实际工具定义。常用顺序为 `product_search` 找目标与对标商品，拿真实商品 ID 后用 `product_video_list` 找关联视频。按缺口用 `video_detail_analysis` 补商品和表现、`video_script_info` 补时间字幕线索。只查能改变选择的样本和字段。视频脚本返回的描述或转写都保留实际来源。缺数据时优先用用户导出、获准的原页面、当地公开作品或本地原片；差异和缺口随结论记录。
4. 逐条登记视频/商品 ID、源链接或本地原片、市场和价格证据、采集日期、统计窗口、可见表现、投放状态和选入理由。筛不到成交对标时，把跨市场、价位不明和只有播放量的样本用作创作参考，写明对标覆盖。价格未知时继续做同类用途观察和已可证实的分镜，把同价带筛选标为待补。

## 看片、改开头、写分镜

- 打开筛中的原片，核对开头、商品首次出现、关键演示、异议处理和收尾。逐段记实际画面、动作、屏上字、口播或无口播、原片时间码和这一段解决的购买疑问。区分原音听辨、人工字幕、机器识别、背景音乐或片中对白。遇到看不到、听不清或只有转写，说明核到的范围，关键链条缺证的可按已核实部分做素材观察。原片只有标题或摘要时保留为待核线索。
- 用 已安装的 $commerce-shot-transfer 写清可借的镜头作用、同款需要重拍的动作和只能留在原商品上的说法。用 已安装的 $short-video-director 找一个购买疑问，写几种可拍的不同开头。每个开头给第一画面、第一句和屏上短字，说明何时用哪一镜兑现。选定一个推进至脚本，依现有素材和用户指定的时长安排。
- 在视听分镜表记录镜号、成片时段、景别/动作、口播/字幕/声音、对应证据编号、素材或补拍指令，以及验收条件。逐镜检查实物结构、手部接触和动作结果、画音时序和说完所需时间。CTA 紧接可见证据，挂与画面一致的变体。需要电商图像分镜或其他前期物料时，可复用 已安装的 $short-video-commerce 的商品档案和提示词工具。用户要求生成视频时，具备原片和要求后，按项目规则交[带货出单复刻](../SKILL.md)。
- 商品和权利会影响可发布的镜头。逐项核实第三方原片、口播、屏内内容和音乐的使用范围。需要重拍时说明同款实物、角度、动作前后以及可用声音。涉及当地发布规则和披露，按实际站点在发布前查官方说明。

## 一份可拍制作单

- **制作任务**　商品/变体、站点与语言、购买疑问、可见证据、拍法、优先做什么以及完成条件。
- **商品事实与参考**　证据表、可比对标和创作参考、实际看片听音范围、缺口。让每条产品主张查得到支持它的素材。
- **开头与视听分镜**　备选开头、主方案、逐镜时间和声音、素材清单、代表性高风险镜头及验收项。
- **发布草稿**　按入口的共用字段编写。首评可补第一购买异议或演示出处。
- **下一条测试**　记录这条主变量和下一次数据窗口。样本不足时保留对标缺口，本地方案仍用可证明的内容推进。
