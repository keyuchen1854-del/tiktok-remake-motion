# 带货出单复刻

## 1. 开工确认

先读[项目规则](../../../AGENTS.md)。新对话只收到复刻原片，或者只说想试流程、看效果，还没说具体改动时，先问：「这条视频的人物、发型、服装和背景想换成什么？哪些按原片保留？」等答复后再打开链接、读取素材、拆解或出图。

用户同时给出原片和明确改动，或明确说按原片复刻，沿用项目模型和流程时直接开工。明确只改一项时，其余沿用原片。续作沿用已确认的改动和进度，除非用户当次更新。商品或口播等内容只在缺项会影响下一步时补问。使用指定人物时读取本次授权提供的人物参考。上传、费用、发布及下载或安装按项目授权。

## 2. 先做出单策划

- **指定原片和复刻需求**。开工后先核对可取得的同款商品证据、可用卖点、目标站点与语言、用户要求改动的内容和要保留的内容。记录原片负责提出什么购买疑问，靠哪一个动作或镜头兑现。依据实物、已核对资料和用户要求确定本次脚本方向。把可见结构、原片话术和未确认的功效、尺码、价格或促销分别留证。有明确原片时可用原片核对带货表达，按实际缺口决定是否需要对标取数。
- **只有商品资料或创作参考**。按[原创带货](references/original-video.md)做商品证据、对标、开头、可拍脚本和素材清单。参考作品用于提取镜头作用。进入本项目的复刻生成时，落实要用的原片和改动要求，再接第 3 节。
- **有发布数据**。按[发布后复盘](references/review.md)对齐观察窗口、留存、商品点击和订单口径，给下一条的一个改动及复测指标。只做策划、拆片或复盘时做到用户指定的交付阶段。
- 制作单用中文，口播和屏幕字按目标语言写并附中文校对。需要发布草稿时附目标语标题、封面短句、标签、首评、同款挂车和披露核对项。正式发布另按本次授权。

## 3. 反推原片并完成完整版改写

1. 调用[视频反推](../video-reverse/SKILL.md)，保留原片哈希、帧率、时长、音轨及真实帧号。看全片样张，逐一复核候选切点邻帧，记录瞬时重构图、连续动作和疑点。补查商品接触、遮挡、翻面、穿戴、扣合、换色和露出的关键帧。源片字幕和机器转写分别记录，注明是否实听。需要与旧分镜对照时，先封存当前原片证据再读取对照。
2. 按[完整版五部分和 43 列规范](references/gem-schema.md)保存全局设定、逐句口播证据、43 列真实分镜、逐镜中英文动作提示词、自检。逐镜写首姿、哪只手接触什么、商品与遮挡状态、末姿及切镜。画面能证明的细节才入商品锁定。目标语口播按规范检查时间和中文校对字数。明确允许变更的人物、发型、服装、背景、商品或语言。有目标改写时按用户要求写完整新提示词。
3. 保留原片时间线和整条源音轨。确定时间线后可用[共用分段工具](../../../../tools/video-remake/README.md)提前切出对应的静音参考段。区分原片镜头和 H3 生成段，保持编号与时码可回查。

## 4. 逐张生成并检查单图，再拼完整宫格

1. 按原片选择首姿、必要中间姿和末姿，用稳定编号绑定帧号。给每张图写静态提示词，标明底图、商品、人物和构图参考；核对可见件数、结构、颜色、纹样、位置、手部接触和遮挡。
2. 先用内置图片模型出一张能暴露人物、场景和商品结构问题的基准单图。对照原帧与实物检查全图和商品局部。基准过关再逐张生成和验收对应干净单图。全部合格后按原编号拼完整宫格，长片可分页。过程产物标实际状态，单图检查通过后才入宫格。只换背景按[项目规则](../../../AGENTS.md#视频背景替换的项目约定)评估保留合格实拍前景。
3. 失败单图按项目的补图条件和次数执行。普通故障、超时或画面不合格时先定位缺陷，再用内置图片模型补一次。连续两次失败就诊断。内置明确审核拒绝时记录结果，核对对应内容符合适用规则后，按既有授权用[本机 Qwen](references/local-qwen.md)对该单图补一次。沿用通过的图，补图过关后回填原编号。
4. 把完整宫格交用户确认。确认前停在宫格阶段。

## 5. H3 代表段、验收及回拼

- 从已确认宫格选一个能验商品结构、手部遮挡或口播衔接的代表段。用[H3 编译规范](references/h3.md)整理实际段内指令。以该段的已确认干净单图、对应静音原片段、改写指令为一组，经 Capsule 校验并核对本批的上传及费用授权后，直接提交一次 H3 代表段。沿用完整版直接提交流程，跳过 Context-IR。
- 实际审看并对照原片与用户要求，检查人物、场景、商品结构、手部接触、动作连续性、口播语言、口型和节奏。状态未知时先查已有任务。问题片段只在项目规定和本批授权内修正一次。代表段通过后才能继续生成其余段落。
- **轻微画面瑕疵的容许范围。** 代表段和后续各段中，开头或收尾构图比原片略宽、人物或背景有轻微瑕疵等情况，单处持续不超过 3 秒，且不影响用户明确提出的需求点和产品一致性时，默认可以接受。人物身份、场景设定和画面连贯性仍须符合任务要求。
- 逐段验收后回拼，按原时序对齐应保留的原声、字幕与图形。保存源帧、单图、宫格、提示词、静音段、任务 ID、实际产物和验收记录。用 `scripts/validate_delivery.py` 检查结构；实际看图、试听、解码和用户验收各记实际结果。

## 6. 当前对话内交付可点播预览

交付成片、代表段、审看版或对比视频前，按[项目视频预览规则](../../../AGENTS.md#视频交付默认在对话内预览)对实际交付文件运行 `tools/check_video_delivery.py`。检查通过时，把工具给出的预览嵌入当前对话，默认暂停、可点击播放，并附原文件链接。预览不可用时说明实际原因，提供已通过技术检查的文件链接。独立窗口、播放器或自动播放按用户当次明确要求。
