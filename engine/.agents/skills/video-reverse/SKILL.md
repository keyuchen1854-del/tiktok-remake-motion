# 视频反推

用带源帧证据的时间线说明参考片怎么拍、怎么剪、商品怎么展示。默认交付 Markdown 分镜和可编辑的逐镜提示词。已有项目规则和本次授权继续适用，后续改写、生成或发布按各自的任务处理。

## 准备证据

1. 定位用户指定的本地原片和旧拆解。网页链接沿用当次原链接读取规则。使用已有本地文件或获准的本地素材，以新目录保存证据。
2. 运行本技能下的脚本。当前实现使用已可用的 Python 3.11+、Pillow、FFmpeg 和 FFprobe。口播使用现成字幕、可试听音轨或已有 faster-whisper 缓存。

   `python "<技能目录>/scripts/collect_evidence.py" "<原片>" "<新证据目录>" --whisper-model "<已有本地模型目录>"`

   模型参数可省略。指定时传入含 `model.bin` 和 `tokenizer.json` 的现有本地目录。检查 `evidence.json` 的音频状态。缺字幕或转写失败时继续核对画面，口播标明证据缺口。沿用已有工具和素材权限。
3. 用 `overview-*.jpg` 看完全片，并用 `cut-pairs-*.jpg` 看每个候选的邻帧。程序输出的是变化候选。高运动、缩放、闪光、字幕变化可能入选。同景小跳切或短暂产品状态可能漏检。能播放原片时同时核对连续画面，尤其检查紧邻候选和动作最密集的时间窗。
4. 对可疑时间和关键商品动作补看连续帧。加 `--frames "90:100,132"` 输出指定原帧，或用现有本地抽帧工具。调整通览密度用 `--step`，调整候选灵敏度用 `--threshold`。补查时可以复用第一次转写。在新目录留补查证据，避免覆盖旧结果。

## 复核与交付

- 按真实剪接划分镜头，分别记录瞬时缩放、连续运动和暂不能确认的变化。起点取切后的第一帧时间戳。镜号覆盖开头至视频结束。首帧编号为 0，区间前闭后开。音频时间线可跨镜头，区分人工校听、已有字幕、机器转写和听不清。
- 每个镜头写清时间范围、主体与景别、动作前后、商品结构和状态、口播或画面文字、关键来源帧。优先核对手从哪里接触商品，何时遮挡、扣合、翻面或放开。动作跨剪接时分别交代切前和切后可见状态。档位、材料、隐蔽扣合等只写源片能确认的内容。
- 输出一份可编辑分镜。提示词按画面、动作顺序和可见商品约束写，内容紧随证据。保留来源帧与疑点，原始话术中的宣传说法注明来源。用户要求接现有生产流程时，按对应 Gem 或轻量版的现有规则交接。
- 用户要求和 Gem 对照时，先单独核原片，再核旧表。区分源片切点和 H3 生成段。报告命中、漏点、误报和商品动作差异。双方尽量使用同片及相同字段。分别记程序预处理和到达同一验收点的实际计时，注明顺序、准备和复核差异。单次样片的结果只适用于该次试跑。
